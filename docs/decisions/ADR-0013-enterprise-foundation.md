# ADR-0013: Enterprise foundation

**Status:** Accepted\
**Date:** 2026-07-25

## Decision

Entra SSO, secure browser/API behavior, client isolation, audit, three-node database redundancy target, snapshots, off-platform backups, restore testing, observability, and disaster recovery are core—not premium or post-launch retrofits.

## Consequences

Milestone 0 must resolve measurable RPO/RTO, database topology, key/secret recovery, and failure testing. Feature progress cannot be used to waive foundational security or recovery gates.
