# ADR-0007: Shared work-record foundation

**Status:** Accepted\
**Date:** 2026-07-25

## Decision

Incidents, service requests, problems, changes, alerts, general tickets, and custom types inherit one work-record foundation and add specialized schema/workflow behavior.

## Consequences

Assignments, comments, attachments, SLAs, permissions, history, APIs, events, and search remain consistent. Built-in types are protected; MSP-defined types compose supported fields, forms, workflows, permissions, SLAs, and automation.
