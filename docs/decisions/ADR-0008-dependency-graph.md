# ADR-0008: Dependency graph

**Status:** Accepted\
**Date:** 2026-07-25

## Decision

Typed, directed, versioned asset/service dependencies are a core platform capability.

## Consequences

V1 includes relationship provenance, confidence, traversal, cycle validation, ticket links, and impact preview. Confirmed and predicted impact remain visibly distinct. Automated topology and root-cause inference follow after trustworthy data exists.
