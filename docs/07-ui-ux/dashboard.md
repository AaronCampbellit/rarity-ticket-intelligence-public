# Dashboard

**Status:** Draft

Dashboards answer operational questions: what needs attention, what breaches soon, what is unowned, what changed, what is unhealthy, and where workload is accumulating.

Widgets are permission- and client-aware, explain their time range and filters, support drill-down, and avoid decorative metrics. The default technician view includes assigned work, unassigned queues, SLA risk, scheduled work, and recent activity. Initial operations views include queue health, intake failures, automation failures, integration health, backup/queue/security health, and platform health. Dashboards are editable and shareable with authorized team, department, queue, or MSP audiences.
