# Security Overview

**Status:** Architecture draft

Rarity assumes hostile networks, compromised browsers, misconfigured integrations, malicious payloads, and insider risk. Controls follow zero implicit trust, least privilege, defense in depth, secure defaults, and complete accountability.

Threat modeling is required for identity, client isolation, browser sessions, public APIs, webhooks, email, attachments, automation, backups, administrator operations, and the software supply chain. Security review is part of feature completion.
