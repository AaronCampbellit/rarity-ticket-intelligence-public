# Security Incident Response

**Status:** Draft

Runbooks will cover account compromise, token exposure, client-isolation failure, malicious attachment, integration abuse, dependency compromise, data exfiltration, ransomware, and backup compromise.

Rarity must support session/key revocation, connection disablement, evidence preservation, scoped containment, audit export, notification workflow, safe recovery, and post-incident review. Security events enter the same observable event framework without leaking protected content.
