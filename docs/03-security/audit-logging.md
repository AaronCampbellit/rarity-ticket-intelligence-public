# Audit Logging

**Status:** Draft

Audit records capture actor, action, object, MSP/client scope, time, source, before/after state or safe diff, reason, correlation, causation, and authorization context. Authentication, permission, secret, export, backup, workflow, automation, and administrative activity are covered.

Audit data is append-only and tamper-evident, separately protected, searchable by authorized roles, retention-governed, exportable, and monitored for gaps. Secret and sensitive payload values are redacted by schema, not best-effort string matching.
