# V1 Roadmap — Technician Platform

**Status:** Core platform and calendar implemented; release qualification active

The [current execution backlog](current-execution.md) tracks corrective work and the
unified calendar browser workspace. Source and historical demo evidence do not
prove current-candidate release acceptance.

1. Platform kernel: identity, authorization, organization/client scope, object/audit/event foundations.
2. Work management: records, specialized types, routing dimensions, ownership, comments, attachments, time, and search.
3. Workflow and SLA: selection, state machines, approvals, calendars, and explainability.
4. Intake and integrations: email, API, monitoring normalization, deduplication, webhooks, and connections.
5. Automation: typed internal actions and secured external HTTP.
6. Dependency graph: relationships, traversal, impact, and work linkage.
7. Enterprise operations: HA, backup/restore, observability, upgrades, security hardening, and performance evidence.
8. Technician experience polish and release readiness.

Each stage includes API, events, permissions, audit, documentation, and recovery—not follow-on work.

See the detailed [Implementation Plan](implementation-plan.md) and ordered [Build Backlog](build-backlog.md).
