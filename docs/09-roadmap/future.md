# Future Platform

**Status:** Directional

Rarity's native PSA includes Opportunities, proposals, Projects, resource planning, Project financials, and Change Orders. Future extensions may include native invoicing and payments, accounting synchronization, procurement, password vault, remote access, monitoring, patch management, network discovery, workflow marketplace, client portal, and permission-scoped AI agents.

These are not V1 commitments. Their purpose is to test whether today’s platform boundaries remain extensible without speculative implementation.
