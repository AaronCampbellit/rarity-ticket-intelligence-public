# V2 Roadmap

**Status:** Directional

Candidate priorities are native invoicing, payments, accounting synchronization, a full client portal, richer service catalog, mobile-responsive client interactions, knowledge publishing, advanced reporting, topology discovery, correlation/root-cause assistance, and broader packaged integrations.

V2 scope is selected using V1 adoption evidence. Deferred work must reuse the same identity, permissions, object, workflow, event, and API foundations.
