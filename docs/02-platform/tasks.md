# Tasks

**Status:** Draft

Tasks represent bounded internal work such as calling a vendor, ordering equipment, reviewing rules, or completing a fulfillment step. They differ from client-facing work records but reuse assignment, due dates, comments, history, permissions, APIs, and events where appropriate.

Tasks may belong to work records, Opportunities, Projects, approvals, or automations. Tasks may contain subtasks. Project tasks do not support dependency relationships.

During Opportunity conversion, the user selects which incomplete Opportunity tasks become Project tasks. Selected tasks retain identity, ownership, estimates, attachments, comments, subtasks, and history. Completed and unselected tasks remain on the Opportunity.
