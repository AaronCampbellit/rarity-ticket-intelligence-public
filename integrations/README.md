# Integrations

Reserved package boundary for separately distributed connectors. Current Graph
email intake, Datto, Teams and webhook implementations live in `backend/internal/`.
An empty directory here does not mean those runtimes are unimplemented.
See [integration contracts](../docs/04-api/integration-automation-ai-contracts.md)
and [provider acceptance](../docs/06-development/integration-automation-ai-acceptance.md).
